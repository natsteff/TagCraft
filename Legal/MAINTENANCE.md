# License and notice maintenance

LICENSE contains the complete, unmodified AGPL-3.0 copied from Shelf Elf at Nate’s direction. TagCraft selects version 3 only, not an automatic later-version grant. Preserve third-party notices and obligations. Do not edit the standard license text.

Legal/CORE-TERMS.txt is an informational usage notice, not a EULA. TAGCRAFT-NOTES.txt explains actual operations and known limitations. No use-only restriction or custom monetary liability cap remains. Increment notice/supplement versions for wording changes. Run scripts/generate-terms.py to generate USAGE-NOTICE.md and LicenseTerms.swift including the full license; --check detects stale copies. Build tooling bundles these documents and Legal sources offline and removes the superseded bundled EULA.

Continue alone records acknowledgedUsageNoticeVersion, acknowledgedUsageNoticeSupplementVersion, acknowledgedUsageNoticeHash, acknowledgedUsageNoticeAppRelease and usageNoticeAcknowledgedAt locally. New builds or notice changes prompt again. Old EULA records remain untouched but are never reused. Quit dismisses before termination without acknowledgment. Do not describe acknowledgment as license acceptance required merely to run AGPL software. Test using disposable preferences; never acknowledge on a user’s behalf.

The standard license is authoritative. The notice adds no licensing restrictions. Shelf Elf is an unmodified local reference. GitHub publication remains subject to project gates.
